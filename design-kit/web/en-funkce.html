Question author

Versioned question banks

Every edit creates a new version of the question. Past attempts keep the original wording.

  • Question bank permissions to read, use and edit – for individuals and whole branches.
  • Questions with one or more correct answers, images, tables, subscript and superscript.
  • Tags (topic, difficulty) at organisation, branch and question bank level.
  • Question approval before questions go into tests (optional).
  • Import and export via an XLSX template.

Instructor

Build a test once, deliver it in many ways

The app works out how many unique test versions your test allows.

  • Test sections with required questions and random picks (minimum–maximum) from question banks. Excluded tags filter out outdated questions.
  • Scoring methods: percentage, points, “all required questions correct”, custom grade bands.
  • Five types of test assignment: supervised in-room exam, personal access codes, public link with a capacity limit, assigned to a group, and print.
  • Supervised in-room exam: participants join with a code or QR code, the instructor admits them to the test and follows the live monitor. A projector screen is ready for the room.
  • Trial run: go through the test as a test taker would. Nothing is counted.

Test taker

Simple, and no account needed

Join with an access code, a link or a QR code in the room. No account needed.

The app does not lock the computer

But it records when the test taker left the test window, and the instructor can see it.

  • Answers are saved after every change. If the connection drops, they wait in the browser and are sent when it comes back. Test takers can see whether everything is saved.
  • Handover to another computer: if a computer freezes, the instructor issues a handover code and the test taker continues where they left off.
  • Question overview, a “Flag for review” button and a timer that warns before time runs out.
  • Keyboard control, labels for screen readers, extra time for individual people.
  • Result and report right after submission, if the instructor allows it.

Print

Any number of test versions on paper

  • A print batch creates question papers, answer sheets and separate answer keys marked as confidential.
  • Every sheet carries a version code. The instructor enters the paper answers and the app scores them.
  • Paper results sit together with online results and statistics.

Results, reports and statistics

Results that stand up

Submitted attempts are chained together and regularly confirmed by a timestamp from an independent authority. Any later change to a result shows up on verification.

  • Attempt detail with answers and a timeline.
  • PDF result report with a verification code and QR code. Anyone can check it online on the Verify a report page, with no sign-in.
  • Release results manually, or make them visible to the test taker right after submission.
  • Question statistics by version: how often a question appeared in a test and how often it was answered correctly.
  • Results export to a spreadsheet.

Administrator

Organisation, branches and rules

Branches and roles

The organisation administrator sees everything; a branch administrator sees only their branch. You invite users by email.

Exam calendar

Planned exams in one place, linked to the test assignment.

Data protection

Results are kept for the period you set, then anonymised. Official records can be excluded from anonymisation.

Your own look

Your organisation’s logo, your own test intro and report footer text. Custom domain on higher plans.

Change log

Who changed what and when: questions, tests, users and settings.

Plan and usage

Overview of attempts used, plan orders and proforma invoices right in the app.

Sign-in and security

Who can do what is visible and traceable

Two-step verification

A code from an app on your phone. Required for everyone who manages questions, tests or users. Organisations can require it for all instructors.

Sign-in link by email

Organisations can allow sign-in with a one-time link instead of a password. It is off by default.

Data kept apart

Each organisation’s data is kept separate, and branches see only their own data. Roles decide who can read, use or edit questions.

Change log

Who changed what and when. Entries cannot be edited or deleted later from the app.

Support only with your consent

Support enters your organisation only with your consent, and administrators get an email about it.

Export and leaving

Export questions, results, reports and verification data any time, with no exit fee.

Accessibility for test takers

Every test taker can take the test

The interface is designed to WCAG 2.1 level AA (EN 301 549). The accessibility statement also lists known gaps.

  • Keyboard control, including going through the test and submitting it.
  • Elements are labelled for screen readers. A manual screen reader test is in preparation.
  • Extra time for individual people, set in advance or during the test.
  • Screen reader text for formulas and notation with subscripts.
