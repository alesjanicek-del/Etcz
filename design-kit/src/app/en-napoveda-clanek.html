Live monitor

Follow an exam in real time. Each test taker’s status, time left and alerts when someone leaves the test window.

Every test assignment has a Live monitor in its details. It refreshes itself every 5 seconds. On the Overview page, there is a Live monitor link for every exam in progress.

Open Test assignments

What the monitor shows

A summary above the table shows how many test takers are writing, how many have submitted and how many have passed. For each test taker:

  • Status: started, not opened yet, writing, submitted or timed out,
  • Answered: how many questions out of the total,
  • Time left: remaining time (“—” once submitted),
  • Result: for submitted attempts, the percentage and Passed or Not passed,
  • Last activity,
  • Alerts – see the table below.

Auto-refresh

The monitor refreshes itself every 5 seconds. Select Pause auto-refresh to stop it, for example when you want to read the data calmly or you use a screen reader.

The button changes to Resume auto-refresh. While paused, select Refresh now to load the current status. Your browser remembers the choice, even after you reload the page.

How to read the alerts

{{I:pozor}}

Leaving the window does not in itself mean cheating. It may be a phone notification or a key pressed by mistake.

If an alert worries you, ask the test taker and follow the exam rules. You can find the full activity log in the result details.

Actions for a test taker

For an attempt in progress, select Actions. You can extend the time, allow handover to another device or end the attempt. The steps are in the chapter Extending time, handover and ending an attempt.
