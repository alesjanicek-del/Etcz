Verify an exam report

Find out whether a result report or certificate is genuine and has not been changed since the exam.

You’ll find it on the report or certificate, next to the QR code. It has 20 characters in the format XXXXX-XXXXX-XXXXX-XXXXX. You don’t need to type the hyphens or spaces.

How verification works

  1. 01

    Scan the QR code

    The QR code on the report or certificate opens the verification result directly. Or type the code into the field above.

  2. 02

    Compare the details

    The page shows the organisation, test, date and result. Compare them with the paper.

  3. 03

    Check the certificate’s validity

    If the exam has a certificate, you’ll also see the training name, the “Valid until” date and the certificate status.

{{I:info}}

What verification confirms

That the details match the record made during the exam and that nobody has changed them since. It does not assess whether the exam met regulatory requirements.

To protect personal data, the test taker’s name is shown only as initials, for example “J. N.”
