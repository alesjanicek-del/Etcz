Invite new users, assign roles in branches, deactivate accounts and give learners extra time.

Open **Administration** → **Users**. Branch administrators only see users in their own branches.

## Overview

You can filter the list: **Search** by name, email or staff number, **Role** and **Branch**. A user’s status is active, invitation pending or inactive. The **Verification on** badge means the user has turned on two-step verification.

## Inviting a new user

1. Click **Invite user**.
2. Fill in **Full name**, **Email** and, if needed, **Staff number**.
3. For people with a disability, choose **Extra time in tests** (25%, 50% or 100%).
4. Choose **Role** and **Branch**. Branch administrators, instructors and learners must belong to a branch.
5. Click **Create and send invitation**.

The user receives an email with a link that is valid for 7 days. They set their own password. You never see it.

Your plan limits the number of staff users (administrators, instructors and question authors combined). Learners do not count.

## User details

- **Edit details**. Only an organisation administrator can change the sign-in email. Changing the email signs the user out on all devices.
- **Resend invitation** and **Cancel invitation**.
- **Deactivate** and **Activate**. A deactivated user cannot sign in and is signed out on all devices.
- Roles: to add a role, choose the role and branch and click **Add role**. To remove a role, click **Remove**. One user can have several roles in different branches.

Branch administrators can assign roles only in their own branches. They cannot appoint organisation administrators. They can edit details, deactivate users and reset two-step verification only for users whose roles are all in branches they manage. The organisation administrator manages question authors and users with a role in another branch.

## The user does not know how to sign in

Resend the invitation. If they already have an account, they can use **Forgotten password** on the sign-in page.

*For roles: Branch administrator, Organisation administrator*
