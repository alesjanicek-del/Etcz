# FAQ and troubleshooting

Questions and tests, printing and your account – what the messages mean and what to do.

## Questions and tests

**I can’t save a question with an image.** The image has no description (alt text). Click the image and add a description (see [Editor, images and accessibility](../autor/editor-a-pristupnost.md)).

**My new or edited question is missing from the test.** Approval is turned on and the question has not been approved yet. Or the question is in **Deleted items**, or the section’s tag filter excludes it.

**“After exclusions, N questions remain; you require M.”** The section has too few questions to choose from. Reduce the number of randomly selected questions, remove some exclusions or blocked tags, or add questions to the question bank.

**I can’t go to the Review step.** The test contains errors. You will find them in the **Sections** step.

**I can’t see a question bank or test that a colleague created.** Your colleague must grant you permission: to you, to a branch where you have a role, or to the whole organisation. It does not depend on the active branch.

**I can’t see the button for a new question bank or new test.** Your organisation does not allow instructors to create question banks and tests. Ask your administrator.

**I edited a question during an exam. Does it change for test takers who are taking the test right now?** No. Attempts in progress and printed test versions keep the original version. Only newly started attempts get the new version.

**A test taker sees “The test cannot be started now”.** A test version cannot be created from the test, usually because a required question is not approved or has been deleted. **Test version preview** shows the cause.

## Printing

**“Another print batch is being generated in this branch.”** Wait until the previous batch is finished. Other branches can print at the same time.

**“The number of test versions exceeds your plan’s annual attempt limit.”** Contact your organisation administrator.

**I can’t see a print batch from a colleague in another branch.** This is intentional. Only users in the same branch and the organisation administrator can see print batches and answer keys. If you have a role in more than one branch, switch the active branch.

## Account

**A link from an email showed “You are signed in with a different account”.** Another user is signed in in the browser (for example, an administrator on a shared computer). Click **Sign out and continue**: the app signs that person out and opens the link for the right account. Save any unfinished work first.

**I didn’t get an invitation or a password reset link.** Check your spam folder. Your administrator can resend the invitation, even if it has expired. If the password reset link did not arrive, request a new one with **Forgotten password**.

**I’ve lost the phone with my authenticator app.** See [Two-step verification](../zaciname/overeni-ve-dvou-krocich.md).

**The app signed me out.** See [Signing in, password and signing out](../zaciname/prihlaseni.md).

## Didn’t find an answer?

Ask your organisation’s administrator. The customer’s authorised representative or the organisation administrator can submit a support request (see [Reporting a fault and support requests](../objednatel/hlaseni-vady.md)).

*For roles: Question author, Instructor, Branch administrator, Organisation administrator*
