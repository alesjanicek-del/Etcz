Draft, submitting for approval, approving or returning with a comment. Only the approved version goes into tests.

The organisation administrator turns on approval in **Organisation settings** with the **Question approval** option. When it is off, a question is valid as soon as it is saved.

## Question statuses

**Draft** → **Pending approval** → **Approved**.

## Author

1. Save a question you are still working on with **Save as draft**.
2. Submit a finished question with **Submit for approval**.

If the approver returns a question to you, it is marked **Returned to draft** in the question list and in its details. You see the approver’s comment there (you also get it by email). Correct the question and submit it again.

## Approver

Organisation administrators can approve questions. Branch administrators can do so only if the organisation allows it with the **Branch administrators can also approve questions** option.

1. Open **Questions → Pending approval**.
2. Review the question. The **History and differences** link shows the changes from the previous version.
3. Select **Approve**. Or fill in **Comment for the author** and select **Return to draft**.

## What approval means for tests

- Only the approved version of a question goes into new test versions.
- An edited question is left out of the selection until someone approves its new version. The older version is not used in its place.
- If such a question is mandatory in a test, the test cannot start until someone approves it. [Preview test version](../lektor/nahled-a-nanecisto.md) shows the reason.

*For roles: Question author, Instructor, Branch administrator, Organisation administrator*
