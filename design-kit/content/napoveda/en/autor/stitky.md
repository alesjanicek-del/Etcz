Sorting questions with tags in lists at organisation, branch, instructor or question bank level.

Tags help you sort questions and pick questions for tests (allowed and blocked tags). A question can have several tags from different lists.

## Tag lists and their scope

Tags are organised in tag lists. Each list has a scope:

| Scope | Who sees and uses the list |
|---|---|
| Organisation | all instructors in the organisation |
| Branch | branch members |
| Instructor | only you |
| Question bank | anyone with access to the bank |

## New tag list

1. Open **Questions → Tags**.
2. Select **New tag list**.
3. Fill in **Tag list name** and choose a **Scope**. For the branch or bank scope, also choose the branch or bank.
4. Select **Create list**.

## Tags in a list

1. On the list, select **Manage**.
2. Under **Add tag**, fill in **Name**, choose a **Colour** and select **Add**.

You can rename a tag or change its colour, then save with **Save**.

You can delete only a tag that has never been assigned to any question. For a tag in use, the application keeps its history, so just rename it.

## Assigning tags to a question

In the question editor, tick tags in the **Tags** section. You only see the lists you are allowed to use in that bank.

The [question history](verze-a-historie.md) shows when each tag was added to or removed from the question.

*For roles: Question author, Instructor, Branch administrator, Organisation administrator*
