Every change to a question creates a new version. The history shows who changed what and when, and the difference between versions.

## Why versions

Every change to a question’s content creates a new version that cannot be changed. This means that:

- the result report always shows exactly the version of the question that the test taker saw,
- later changes do not affect submitted attempts or printed test versions,
- new test versions of all tests that use the bank always get the latest question version.

Changing the **Internal note** field does not create a new version, but it is recorded in the history.

## Question history

In the question details, select **History**. You see:

- the **Versions** table: who made the change, date and time, **Change summary** and how many times the version was used in test versions. The current version is marked “current”,
- **Difference between versions**: choose **From version** and **To version**, then select **Compare**. Lines starting with “−” were removed, and lines with “+” were added. The [x] mark shows a correct answer,
- the tag history and records about the question (creation, new versions, approval, moves).

## Changes during an exam

Did you edit a question while an exam is running? Attempts in progress and printed test versions keep the original version. Only newly started attempts get the new version.

Statistics by version show which versions were actually used in exams (see [Statistics](../lektor/statistiky.md)).
