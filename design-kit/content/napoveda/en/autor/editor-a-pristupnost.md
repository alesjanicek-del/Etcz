Text formatting, superscript and subscript, tables, images with descriptions, and text for screen readers.

## Toolbar

You can use the toolbar above the question text with a mouse or with the arrow keys. It contains:

- **Bold** (Ctrl+B), **Italic** (Ctrl+I), **Underline** (Ctrl+U),
- **Superscript** (Ctrl+.) and **Subscript** (Ctrl+,),
- **Bulleted list** and **Numbered list**,
- **Insert table**, plus **Add table row**, **Add table column** and **Delete table**,
- **Insert image**, **Edit image description** and **Screen reader text**.

Formatting is kept in printed question papers and in the result report too.

## Why accessibility matters

Test takers who are blind or have low vision and use a screen reader must be able to take the test too. A screen reader cannot see an image and does not know how to read ¹³⁷Cs. So follow the guidelines below.

## Images must have a description

1. Select **Insert image** and choose a file: PNG, JPEG or WebP, up to 5 MB.
2. The **Describe inserted image** window opens. Leave the image type as **Informative** if the image carries information needed to answer (a chart, diagram or symbol).
3. Fill in **Image description (alternative text)** and select **Save**. Write the description so that the question can be answered from it. For example, “Decay curve chart, activity halves every 30 years”.

To change the description later, select the image and then **Edit image description**.

You cannot save an informative image without a description. Nor can you save a question that contains one.

## Decorative images

Is the image only decoration that nobody needs in order to answer (a logo, a decorative line, an illustrative photo)? In the **Describe inserted image** window, choose the type **Decorative** and select **Save**. You do not fill in a description.

- Screen readers skip the image, so it does not slow the test taker down.
- In print and in PDFs, the image stays without a description.
- In the question’s version history, the image is marked as decorative.

If you are not sure, choose **Informative** and describe the image. A decorative image must not carry anything needed to answer.

## Add screen reader text for indices and formulas

A screen reader would read ¹³⁷Cs or H₂O in a way nobody understands.

1. Select the text.
2. Select **Screen reader text**.
3. Type how it should be read. For example, “caesium one hundred and thirty-seven” or “water, H two O”.

The test taker sees the usual notation on screen, and the screen reader reads your text.

## Other guidelines

- Do not use colour as the only way to convey information (“the correct option is the red one”).
- Do not insert text as an image.
- Fill in the column headers in tables.
