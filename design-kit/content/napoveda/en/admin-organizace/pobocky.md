Create, edit, deactivate, close with data transfer and delete branches.

A branch is an organisational unit, such as a regional office. It keeps tests, print batches and results separate.

Open **Administration** → **Branches**. The overview shows the administrators, instructors and status of each branch.

Branch administrators only see the branches they manage. Only organisation administrators can create and edit branches.

## New branch

1. Click **New branch**.
2. Fill in **Branch name** and **Code**. The code is a short abbreviation without diacritics, for example PRAHA. It must be unique within the organisation.
3. Choose a **Colour**. A coloured stripe appears next to the active branch switcher.
4. Save.

Your plan limits the number of branches. When you reach the limit, you see “Your plan’s branch limit (N) has been reached”.

## Editing and deactivating

- **Edit** changes the name, code or colour.
- **Deactivate** turns the branch off temporarily. Instructors cannot create new test assignments in it. Click **Activate** to turn it back on.

## Closing or deleting a branch

Next to the branch, click **Close or delete**.

- **The branch has no history** (no users, data or exams): you can delete it with **Delete branch**.
- **The branch has history**: you cannot delete it. Choose a **Target branch** and click **Close branch and transfer**. Users, groups, tags, question banks and tests move to the target branch. The closed branch is deactivated. The page shows in advance what will move and what stays with the original branch.

Organisation administrators can still see exam results from a closed branch.

*For roles: Organisation administrator, Branch administrator*
