# Verifying a result report

How anyone, without signing in, can check that a result report or certificate is genuine and unchanged, and whether a certificate is still valid.

Every result report and certificate has a verification code and a QR code. A certificate has the same code as the result report for the same exam. Anyone you show the code to can check that it is genuine, for example an employer or a public authority. No sign-in is needed.

## Steps

1. Scan the QR code on the result report or certificate. Or open the **Verify a result report** page: the address ends in `/overeni` and is printed on the report. On the app’s website, the **Verify report** link takes you there.
2. Enter the **Verification code** from the report or certificate.
3. Click **Verify**.

## Certificate validity

If the exam comes with a certificate, the page also shows the training name, the **Valid until** date and the **Certificate status**:

- **valid** or **valid indefinitely**: the certificate is valid,
- **expired**: the certificate has expired and the training must be repeated,
- **invalid (record superseded or invalidated)**: the result was corrected or the attempt was invalidated; the correction record or replacement attempt applies.

The expiry date is part of the verified record, so nobody can change it afterwards. The certificate is issued by the organisation named on it; it is not an official document from a public authority.

## What the result means

| Message | Meaning |
|---|---|
| The result report matches the record in the app and has a timestamp (from a qualified authority, a “qualified timestamp”). | The report is genuine. Compare the details shown (organisation, test, date, result) with the paper copy. |
| The record is stored. It will receive a timestamp within an hour; you can then verify again. | The exam took place recently. Verify again later. |
| The record content matches. However, we found a discrepancy in the time it was written that needs checking. | The record content is fine, but the write times do not match (for example, because a clock was set wrongly). No change to the content has been found. Contact the exam organiser, who will check the times. |
| The record does not match – it has been changed. | The record was changed after submission. Contact the exam organiser. |
| The result report has been superseded by correction record … and is no longer valid. | The paper exam was corrected (an error when entering the answers). The result report with the verification code shown is the valid one. |
| The organisation no longer uses the app; verified against the verification data archive. | The report is genuine. It is verified against the archive kept after the organisation’s contract ended. If the organisation asked for the result to be removed from the archive, the result shows “not stated”. The report can still be verified. |
| After reviewing the exam, the organiser invalidated attempt …; the result report is not valid. The replacement attempt has verification code … | After reviewing an automatic submission by monitoring, the organiser invalidated the attempt. The replacement attempt’s result report is the valid one. |
| The attempt was ended by an automatic monitoring rule; the organiser has not yet reviewed the result. | Exam monitoring submitted the attempt (for example, after the test taker left the window repeatedly), and the organiser has not yet decided whether to accept the result. Verify again later or contact the organiser. |
| No record with this code was found. | Check that you typed the code correctly. |

Verification confirms that the details match the record made during the exam and that nobody has changed them since. It does not assess whether the exam met regulatory requirements.

To protect personal data, the test taker’s name is shown only as initials, for example “J. N.”. For an anonymised record, you see “personal data anonymised”. The result can still be verified.

*For roles: everyone*
