# How to get to your test

Access code, supervised in-room exam, a link from the organiser or a learner account.

What you do depends on what the organiser gave you. You do not need to install anything; a browser on a computer, tablet or phone is enough.

## I have an access code

You received the code on paper or by email.

1. Open the code entry page. The address ends in `/kod`, and the organiser will give it to you. On the sign-in page, the **Enter access code** link takes you there.
2. Type the code into the **Access code** field. Hyphens, spaces and capital letters do not matter.
3. Click **Continue to test**.

If you enter the code wrongly several times, the app blocks code entry for a while. It shows when you can try again.

## I am at a supervised in-room exam

1. Scan the QR code on the projector screen with your phone. Or open the address shown on the projector screen and fill in **Exam code (from the projector screen)**.
2. Fill in **Full name**.
3. Click **Join**.
4. You are now in the waiting room: “Wait for your instructor to start the test.”. Do not close the page; it refreshes by itself. As soon as the instructor starts the test, the first question appears.

Do you see “The test is starting” in the waiting room? The instructor has just started the test. Wait; the first question opens by itself.

After clicking **Join**, do you see the error “Entry to this exam is already closed”? The instructor has locked entry and is not accepting new participants. Speak to the instructor.

Do you see “You have been removed from the waiting room”? Speak to the instructor and join again.

## I have a link

Click the link. The test start page appears. Depending on the settings, the app may ask for your name.

## I have a learner account

1. Sign in (see [Signing in](../zaciname/prihlaseni.md)).
2. The **My tests** page opens with your assigned tests.
3. Next to the test, click **Start test**. For a test in progress, click **Continue test**.

If the test has not started yet, you see when it will be available (for example, “You can start the test from 15 Jan 2027, 09:00.”). If it has already ended, you see **Not available**. The time limit shown for the test includes any permanent extra time you have.

*For roles: Test taker, Learner*
