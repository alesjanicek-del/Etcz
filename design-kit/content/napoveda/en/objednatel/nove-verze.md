# New versions of the app

How you hear about new features, when the app is updated and where to find the current user guide.

## What’s new

You will find the new features in each version under **What’s new** in the menu. The same overview is also in help, where new features for your role are marked “for you”.

The number of the version you are using is at the bottom of the left-hand menu.

## When the app is updated

- The operator does not install new versions during an exam entered in the exam calendar, or in the 2 hours before or after it.
- A bar at the top of the page warns you in advance about planned maintenance.

## Current user guide

The help in the app always matches the version you are using. You can download the user guide for your role as a PDF from the [help home page](../index.md). The cover page shows the version number and date.

*For roles: everyone*
