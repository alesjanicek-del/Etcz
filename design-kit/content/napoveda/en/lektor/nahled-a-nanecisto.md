How to view a randomly drawn test version and try the test as a test taker without the attempt counting.

## Preview test version

**Preview test version** draws one possible version of the test. Nothing is saved.

- Select **Another version** to draw a different one.
- Use the switch to choose the test taker’s view (correct answers hidden) or to show the correct answers.
- Mandatory questions are labelled “Mandatory”.

If a test version cannot be created, the preview shows why. For example, a mandatory question is not approved, or a section has too few questions.

## Start trial run

**Start trial run** opens the real test exactly as a test taker sees it. After you submit, it shows the result.

A trial run does not count towards results, statistics or your plan’s limit. It is deleted after 24 hours.

## Each test taker gets a different test version

A test version is only created when the test starts, from the current versions of the questions. So each test taker gets their own selection and order of questions and answers, following the section rules. The **Check** step shows how many different test versions are possible. A unique test version is made up of the selection of questions, the question order and the answer order. Selections of questions that nobody has had yet are handed out first. A trial run does not use up a unique test version.
