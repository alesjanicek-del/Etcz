Supervised in-room exam, personal access codes, assignment to learners, anonymous link and print. What you fill in and what you get.

In the application, each time you give a test in a particular way is called a **test assignment**.

## How to create an assignment

1. On the **Tests** page, select **Assign** next to the test, or **Assign test** in the **Check** step.
2. Choose a method by selecting **Choose: …**.
3. Fill in the common fields: **Label** (for example “Exam 12 Nov – Prague”), **Available from** and **Available until**. If needed, add extra time for the whole assignment.

The assignment belongs to your active branch.

## Methods at a glance

| Method | For whom | What you fill in | What you get |
|---|---|---|---|
| Supervised in-room exam | people in the room without an account | only the label | a waiting room, plus a code and QR code for the projector screen |
| Personal access codes | named people without an account | **People**: one per line in the form `Name; email; extra time in %` (email and extra time are optional) | a code table that is shown only once. Print it with **Print** and hand out the codes, or email them straight away (option under **Send by email**, plus a **Custom email text (optional)** field if you want one) |
| Assigned to learners / a group | learners with an account | **Learner groups** or **Individual learners** | the test appears in their **My tests** |
| Link (anonymous) | anyone with the link, practice tests | maximum attempts via the link, maximum attempts in progress at once, and whether to ask for a name | a link for test takers |
| Print | paper exam | see [Printing paper test versions](tisk.md) | PDFs of question papers, answer sheets and answer keys |

## Codes

- Codes are entered on the `/kod` page. Give test takers the address together with their code. You can also hand out **Instructions for test takers**.
- The code table is shown only once. Save or print it straight away.
- In the assignment details, expand **Access codes**. You can see how many times each code has been used. Select **New code** to issue a replacement code. The old one stops working. Select **Email new code** to send the replacement code straight to the person’s email.

## Links

You can create several links for one test, each labelled with its purpose, for example “Email March” and “Website”. You can then compare results by link (see [Results and result reports](vysledky-a-protokol.md)).

You cannot use a link for an official test, or if your organisation has turned links off.

## Assignment list

**Tests and exams → Test assignments** shows open assignments and, if you choose, closed ones too. From the assignment details, you can go to the **Live monitor** and to **Results**.

## Closing an assignment

In the assignment details, select **Close**. No new test takers can join: the link and unused codes stop working. Attempts in progress can still be finished. When an attempt runs out of time, the application submits it automatically.

*For roles: Instructor, Branch administrator, Organisation administrator*
