How to give a test taker more time, let them continue on another device or end an attempt early.

For an attempt in progress, select **Actions** in the live monitor.

## Extend time

1. In the **Actions** menu, fill in **Extend by (min)** (1 to 240) and **Reason** (required).
2. Select **Extend time**. There is no further confirmation.

Within 30 seconds, the test taker’s timer changes and a message appears: “Your instructor has given you … more minutes”. Screen readers read it out. The extension is recorded in the attempt record and in the change log.

## Extra time in advance

For people with a disability, set the extra time in advance:

- for a code: in the third column of the person’s line (for example `Jan Novák; ; 50`),
- for a learner: in the **Extra time in tests** field of their account. An administrator sets this.

You set extra time for a whole assignment when you create it.

## Allow handover to another device

Has the test taker’s phone run out of battery, or do they need a different computer?

1. Fill in **Handover reason** (required), for example “phone battery flat, continuing on PC 5”.
2. Select **Allow handover to another device**.
3. The application shows a handover code. It is valid for 10 minutes.
4. Give the code to the test taker. On the new device, they enter it on the code entry page, in the **Handover code from instructor** field.

The test is blocked on the original device. The handover and its reason are recorded in the attempt record. In the result and the result report, the attempt is marked “Completed after handover to another device”.

For an official test, only an organisation or branch administrator can allow a handover.

## End attempt

After you confirm, **End attempt** submits the attempt immediately. It is evaluated with the answers saved up to that moment. In the results, it is marked as submitted by the instructor. You cannot undo this.

The test taker sees “Test ended by instructor” and the time it ended.

*For roles: Instructor, Branch administrator, Organisation administrator*
