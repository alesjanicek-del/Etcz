A print batch with question papers, answer sheets and answer keys, separation by branch and entering paper answers.

## Creating a print batch

1. On the **Tests** page, select **Assign** next to the test, then **Choose: …** for the **Print** method. This option is offered only if your organisation’s plan includes printing.
2. Check the branch. The batch belongs to your active branch.
3. On the right is **Preview one test version**. Nothing is saved.
4. Fill in **Number of test versions** (up to 500 per batch) and, if you like, **Label (optional)**.
5. Select **Create batch**.

Each printed test version counts as an attempt towards your plan’s annual limit.

The form shows how many unique test versions the test still allows (a different selection of questions, question order or answer order). You can print any number. If you enter more than the unique versions left, the extra versions repeat the least used combinations. The form, the batch page and the answer key all tell you so. In the answer key, repeated versions are marked “repeated combination”. To get more unique test versions, widen the question selection or turn on shuffling.

The batch is prepared in the background. The page refreshes itself. When it is ready, you can download:

- **Question papers (PDF)**: all test versions, each with a code in the header,
- **Answer sheets (PDF)**: sheets with the version code, a QR code and an answer grid,
- **Answer keys and scoring table (PDF)**: confidential. Do not give them to test takers.

Every download is recorded in the change log.

## Batch list

You can find all print batches in **Tests and exams → Print**. You see your active branch’s batches, including those created by colleagues in the same branch. You cannot see other branches’ print batches and answer keys, even if you know the link.

## Entering paper answers

Paper answers are entered by the instructor who created the test assignment, or by a branch administrator. Other instructors in the branch can see the batch and answer keys, but cannot enter answers. Only the assignment’s creator and administrators can see its results.

1. In the batch, select **Enter paper answers**.
2. Type in the **Version code** from the answer sheet, or scan it with a QR code reader. Select **Select version**.
3. Fill in **Test taker’s name** and, for each question, tick the letters marked on the sheet. For an unanswered question, leave “—”.
4. Select **Enter and evaluate**.

The result appears straight away. In **Results**, it is marked “paper”.

Made a mistake while entering answers? A submitted attempt is not overwritten. Enter the code of the same test version again, fill in the correct answers and the **Reason for correction** field, then select **Save corrected record**. This creates a new record with the corrected answers. It is evaluated again and gets its own result report and verification code. It replaces the previous result in results and statistics. The original record can still be found, marked **Replaced by correction** (when, by whom and why). You can find it in the result details, in the result report and when verifying the original result report, which links to the valid code. Any further correction builds on the latest valid record. A correction does not count towards the annual attempt limit.

## Common problems

- “Another print batch is being generated in this branch.” Wait until the previous batch has finished. Other branches can print at the same time.
- “The number of test versions exceeds your plan’s annual attempt limit.” Contact your organisation administrator.

*For roles: Instructor, Branch administrator, Organisation administrator*
