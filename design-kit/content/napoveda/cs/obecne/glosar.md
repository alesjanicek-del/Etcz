# Slovníček pojmů

Pojmy v aplikaci a jak odpovídají výrazům ze zadávací dokumentace.

## Pojmy v aplikaci

| Pojem | Význam |
|---|---|
| Organizace | Objednatel, který aplikaci používá, například úřad. |
| Pobočka | Organizační jednotka organizace. Odděluje testy, tiskové dávky a výsledky pracovišť. |
| Aktivní pobočka | Pobočka zvolená v horní liště. Nové záznamy se zakládají v ní a stránka Tisk ukazuje jen její dávky. Výsledky nefiltruje. |
| Administrátor organizace | Spravuje nastavení, pobočky, uživatele a data celé organizace. |
| Administrátor pobočky | Spravuje uživatele a skupiny své pobočky. |
| Lektor | Sestavuje testy, zadává je a vyhodnocuje. |
| Autor otázek | Vytváří a upravuje otázky v souborech otázek. |
| Studující | Osoba s účtem, které lze přidělit test. |
| Zkoušený | Kdokoli, kdo vyplňuje test, s účtem i bez něj. |
| Účastník prezenční zkoušky | Zkoušený, který se připojil kódem z promítací plochy. „Účastník“ se říká lidem v místnosti a v čekárně před spuštěním testu, po spuštění je to zkoušený. Viz kapitola [Prezenční zkouška s čekárnou](../lektor/prezencni-zkouska.md). |
| Soubor otázek | Pojmenovaný okruh otázek s přidělenými právy. |
| Otázka a verze otázky | Každá změna obsahu otázky vytvoří novou verzi. Odevzdané pokusy zůstávají na své verzi. |
| Štítek a seznam štítků | Třídění otázek. Seznamy mají rozsah organizace, pobočka, lektor nebo soubor otázek. |
| Test | Předpis zkoušky: sekce, pravidla výběru otázek a parametry. |
| Sekce testu | Výběr otázek z jednoho souboru otázek. |
| Povinná a vyloučená otázka | Povinnou dostane každý zkoušený, vyloučená se nikdy nevybere. |
| Povolené a zakázané štítky | Filtr otázek, ze kterých se losuje. |
| Variace testu | Konkrétní výběr a pořadí otázek a odpovědí pro jednoho zkoušeného nebo jeden vytištěný arch. |
| Unikátní variace | Variace s jiným výběrem otázek, jiným pořadím otázek nebo jiným pořadím odpovědí (podle nastavení míchání). Aplikace dává přednost výběru otázek, který ještě nikdo nedostal. |
| Použití testu | Jedno zadání testu konkrétním způsobem: prezenční zkouška, kódy, přidělení, odkaz nebo tisk. |
| Prezenční zkouška | Zkouška v místnosti s kódem a QR kódem na promítací ploše a s čekárnou. |
| Přístupový kód | Osobní kód zkoušeného, kterým otevře test. |
| Kód pro převzetí | Jednorázový kód od lektora pro pokračování na jiném zařízení. Platí 10 minut. |
| Heslo testu | Společné heslo k zahájení testu. Je nepovinné a sděluje ho lektor. |
| Odkaz | Anonymní přístup k testu. K jednomu testu může být víc odkazů s označením účelu. |
| Pokus | Jedno vyplnění testu jednou osobou. |
| Úřední test | Režim pro úřední zkoušky: bez odkazů, bez zpětné vazby a bez zobrazení správných odpovědí. |
| Tisková dávka | Variace k tisku s odpovědními listy a klíči. |
| Odpovědní list, klíč, vyhodnocovací tabulka | Tiskové sestavy papírové zkoušky. |
| Způsob hodnocení | Pravidlo, podle kterého se určí, zda zkoušený test splnil (procenta, body, známky). |
| Protokol o zkoušce | PDF záznam pokusu s ověřovacím kódem. |
| Ověřovací kód | Kód na protokolu, podle kterého kdokoli ověří jeho pravost. |
| Živý panel | Sledování průběhu zkoušky v reálném čase. |
| Zkusit nanečisto | Zkušební vyplnění testu lektorem. Nezapočítává se. |
| Ochrana záznamu (legal hold) | Zákaz anonymizace záznamu, například kvůli odvolacímu řízení. |
| Zmocněnec objednatele | Osoba, která za organizaci zadává požadavky na podporu. |
| 2FA | Ověření ve dvou krocích: heslo a kód z telefonu. |

## Pojmy ze zadávací dokumentace

| Výraz v zadávací dokumentaci | Pojem v aplikaci |
|---|---|
| okruh otázek, bazén otázek | soubor otázek |
| studující | studující (s účtem) nebo zkoušený (bez účtu) |
| uchazeč (zkouška ZOZ) | zkoušený |
| lektor | lektor |
| pobočka | pobočka |
| variace testu, unikátní variace | variace |
| zkušební list | odpovědní list |
| vyhodnocovací tabulka, klíč | klíče a vyhodnocovací tabulka |
| prezenční školení | prezenční zkouška |
| přidělení kódem nebo heslem | přístupové kódy pro osoby, heslo testu |
| odkaz pro anonymní přístup | odkaz (anonymní) |
| sledování průběhu v reálném čase | živý panel |
| protokol s dohledatelným záznamem | protokol o zkoušce s ověřovacím kódem |

*Pro role: všichni*
